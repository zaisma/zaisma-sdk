# Error codes

Every error the developer API and MCP answer with, as `{ "error": { code, message, field, fix, message_for_people, retry_after_sec, help_url } }`. A thrown error's own `fix` is more specific than the general one here: do what it says first. Each code's page is at `help_url`.

## Signing in and requests

- `no_key` (HTTP 401): The MCP was called without an API key or a connected app's token. Fix: Send an API key as Authorization: Bearer <key>, made on zaisma.com/account, or connect the MCP at https://zaisma.com/mcp and sign in. https://zaisma.com/developers/errors/no_key
- `bad_key` (HTTP 401): The API key isn't valid: removed, mistyped or never made. Fix: Make a new API key on zaisma.com/account and send it as Authorization: Bearer <key>. https://zaisma.com/developers/errors/bad_key
- `key_turned_off` (HTTP 401): The API key was found in public and turned off for good. Fix: Make a new API key on zaisma.com/account and keep it out of public files, like a game's code or a public repository. https://zaisma.com/developers/errors/key_turned_off
- `key_ended` (HTTP 401): The API key reached the end date it was made with. Fix: Make a new API key on zaisma.com/account, with a later end date or none. https://zaisma.com/developers/errors/key_ended
- `access_token_ended` (HTTP 401): A connected app's access token is past its hour; the app refreshes it by itself. Fix: Refresh the token with the refresh token from the sign-in, as the MCP app does by itself, or connect the app again. https://zaisma.com/developers/errors/access_token_ended
- `token_not_for_api` (HTTP 401): A connected app's token works only at the MCP, not the REST API. Fix: Call the MCP at https://zaisma.com/mcp with this token, or make an API key on zaisma.com/account for the REST API. https://zaisma.com/developers/errors/token_not_for_api
- `signed_out` (HTTP 401): No API key, and no signed-in session. Fix: Send an API key as Authorization: Bearer <key>, or sign in on zaisma.com first. https://zaisma.com/developers/errors/signed_out
- `no_account` (HTTP 401): The account isn't finished yet. Fix: Finish making the account on zaisma.com/join, then call again. https://zaisma.com/developers/errors/no_account
- `bad_origin` (HTTP 403): A call with a session came from another site. Fix: Call the API with an API key from your own server or tools, never with a zaisma.com session from another site. https://zaisma.com/developers/errors/bad_origin
- `key_not_allowed` (HTTP 403): The API key is limited to other games, or its access doesn't cover the call. Fix: Call get_access to see what the key covers, then make a key on zaisma.com/account with the games and access this call needs. https://zaisma.com/developers/errors/key_not_allowed
- `slow_down` (HTTP 429): Too many calls in a minute. Fix: Wait retry_after_sec seconds, then call again, and space calls out from then on. https://zaisma.com/developers/errors/slow_down
- `not_found` (HTTP 404): There's no API call at that path. Fix: Check the path against docs/DEVELOPER-API.md: every path starts with /api/dev, like GET /api/dev/games. https://zaisma.com/developers/errors/not_found
- `bad_method` (HTTP 405): The path doesn't take that method. Fix: Send the call with a method the path takes, as docs/DEVELOPER-API.md lists it. https://zaisma.com/developers/errors/bad_method
- `gone` (HTTP 410): The call was removed, like the first feedback calls. Fix: Use the call the message names instead, as docs/DEVELOPER-API.md lists it. https://zaisma.com/developers/errors/gone
- `bad_json` (HTTP 400): The body isn't a JSON object. Fix: Send the body as one JSON object with Content-Type: application/json. https://zaisma.com/developers/errors/bad_json
- `json_too_big` (HTTP 413): The JSON body is over the call's size limit. Fix: Send less in one call, in parts, or use the upload command for files. https://zaisma.com/developers/errors/json_too_big
- `wrong_shape` (HTTP 400): A field that isn't the type or size its call takes, refused before any of the call's own code runs. Fix: Change the field named in field to the type and size the call takes, as the MCP tool's input schema says. https://zaisma.com/developers/errors/wrong_shape
- `unknown_field` (HTTP 400): A field, argument or query parameter the call doesn't take. Fix: Leave out the field named in field: the MCP tool's input schema lists every field the call takes. https://zaisma.com/developers/errors/unknown_field
- `missing_field` (HTTP 400): A field the call needs wasn't sent. Fix: Send the field named in field, as the MCP tool's input schema says. https://zaisma.com/developers/errors/missing_field
- `wrong_id_kind` (HTTP 400): An ID of another kind was sent, like an image ID as version_id. Fix: Send an ID of the kind the field names, like a version_… ID as version_id, from the call that answered it. https://zaisma.com/developers/errors/wrong_id_kind
- `internal_error` (HTTP 500): Something broke on Zaisma's side. Fix: Call again in a minute, and if it keeps happening, tell Zaisma with message_zaisma, kind bug. https://zaisma.com/developers/errors/internal_error

## Games

- `no_game` (HTTP 404): You have no game with that slug. Fix: Call list_games for your games' slugs, then call again with one of them. https://zaisma.com/developers/errors/no_game
- `bad_slug` (HTTP 400): The link name isn't lowercase letters, numbers and single hyphens, or is reserved. Fix: Give a slug of lowercase letters, numbers and single hyphens, like space-race, that isn't one Zaisma keeps. https://zaisma.com/developers/errors/bad_slug
- `slug_taken` (HTTP 409): Another game has that link name, or a deleted game had it. Fix: Give create_game another slug, or leave slug out to have one made from the title. https://zaisma.com/developers/errors/slug_taken
- `slug_locked` (HTTP 409): new_slug can't change the link: the game isn't a private draft, or was published, or has tester links or kept rooms. Fix: Make a new game for a new link: a link changes only while the game is a private draft never published, with no tester links or kept rooms (can_change_slug). https://zaisma.com/developers/errors/slug_locked
- `too_many_games` (HTTP 403): The account holds as many games that no players play as it can. Fix: Delete a game you don't need with delete_game, or get players on one: a game with real players frees its slot. https://zaisma.com/developers/errors/too_many_games
- `account_banned` (HTTP 403): Zaisma banned the account's developer side, or the whole account: only get_access, list_games and export_game work, and for a whole-account ban nothing does. Fix: Export your games with export_game to keep them, and read the ban's reason in get_access. https://zaisma.com/developers/errors/account_banned
- `account_paused` (HTTP 403): A person at Zaisma needs to look at the account: until then it can't make, upload or publish games, or post on the forum. Fix: Wait for a person at Zaisma to look at the account; get_access says why it's paused, and message_zaisma reaches them. https://zaisma.com/developers/errors/account_paused
- `publishing_not_open` (HTTP 403): Until the beta, only accounts Zaisma adds can make, upload and publish games. Fix: Call get_access to see can_publish, and ask Zaisma for access with message_zaisma until the beta opens. https://zaisma.com/developers/errors/publishing_not_open
- `bad_title` (HTTP 400): A game's, topic's or precedent's title is empty or too long. Fix: Give a title that isn't empty and fits the field's length, as the input schema says. https://zaisma.com/developers/errors/bad_title
- `fake_reward_words` (HTTP 400): A game's title or description promises a fake reward: another platform's currency or something of real value, like free Robux, V-Bucks, gift cards or cash. Fix: Take those words out of the title or description. https://zaisma.com/developers/errors/fake_reward_words
- `title_names_zaisma` (HTTP 400): A game's title holds the whole word Zaisma, which only Zaisma's own games can use. Fix: Give the game a title without the word Zaisma. https://zaisma.com/developers/errors/title_names_zaisma
- `bad_description` (HTTP 400): The description isn't text of up to 500 characters. Fix: Give a description of up to 500 characters of plain text. https://zaisma.com/developers/errors/bad_description
- `bad_visibility` (HTTP 400): visibility isn't draft, listed, unlisted or private. Fix: Give visibility as listed, unlisted, private or draft. https://zaisma.com/developers/errors/bad_visibility
- `bad_devices` (HTTP 400): devices isn't a list of phone, tablet and computer. Fix: Give devices as a list from phone, tablet and computer. https://zaisma.com/developers/errors/bad_devices
- `bad_genres` (HTTP 400): genres isn't a list of up to 3 of Zaisma's genres. Fix: Give genres as a list of up to 3 of the genres update_game's input schema lists. https://zaisma.com/developers/errors/bad_genres
- `bad_controls` (HTTP 400): controls isn't a list of touch, keyboard_mouse and gamepad. Fix: Give controls as a list from touch, keyboard_mouse and gamepad. https://zaisma.com/developers/errors/bad_controls
- `bad_screen_orientation` (HTTP 400): screen_orientation isn't portrait, landscape, either or null. Fix: Give screen_orientation as portrait, landscape, either or null. https://zaisma.com/developers/errors/bad_screen_orientation
- `bad_play_modes` (HTTP 400): play_modes isn't a list of play modes, or one of them is wrong. Fix: Fix the play mode named in field, as update_game's input schema shows, like { "mode": "online", "minimum_player_count": 2, "maximum_player_count": 4, "play_style": "co-op" }. https://zaisma.com/developers/errors/bad_play_modes
- `bad_cloud_saves_enabled` (HTTP 400): cloud_saves_enabled isn't true or false. Fix: Give cloud_saves_enabled as true or false. https://zaisma.com/developers/errors/bad_cloud_saves_enabled
- `bad_account_offer_enabled` (HTTP 400): account_offer_enabled isn't true or false. Fix: Give account_offer_enabled as true or false. https://zaisma.com/developers/errors/bad_account_offer_enabled
- `bad_deleted_account_erase_enabled` (HTTP 400): deleted_account_erase_enabled isn't true or false. Fix: Give deleted_account_erase_enabled as true or false. https://zaisma.com/developers/errors/bad_deleted_account_erase_enabled
- `bad_friend_joins_enabled` (HTTP 400): friend_joins_enabled isn't true or false. Fix: Give friend_joins_enabled as true or false. https://zaisma.com/developers/errors/bad_friend_joins_enabled
- `bad_performance_measuring_enabled` (HTTP 400): performance_measuring_enabled isn't true or false. Fix: Give performance_measuring_enabled as true or false. https://zaisma.com/developers/errors/bad_performance_measuring_enabled
- `bad_microphone_enabled` (HTTP 400): microphone_enabled isn't true or false. Fix: Give microphone_enabled as true or false. https://zaisma.com/developers/errors/bad_microphone_enabled
- `bad_room_browsing` (HTTP 400): room_browsing isn't page, game or off. Fix: Give room_browsing as page, game or off. https://zaisma.com/developers/errors/bad_room_browsing
- `bad_multiplayer_mode` (HTTP 400): multiplayer_mode isn't none, relay or own. Fix: Give multiplayer_mode as none, relay or own. https://zaisma.com/developers/errors/bad_multiplayer_mode
- `bad_account_requirement` (HTTP 400): account_requirement isn't none, multiplayer or whole_game. Fix: Give account_requirement as none, multiplayer or whole_game. https://zaisma.com/developers/errors/bad_account_requirement
- `bad_minimum_player_age` (HTTP 400): minimum_player_age_years isn't 13, 16 or 18. Fix: Give minimum_player_age_years as 13, 16 or 18. https://zaisma.com/developers/errors/bad_minimum_player_age
- `accounts_needed_for_minimum_age` (HTTP 400): A game for 16 or 18 and up needs account_requirement whole_game, since only accounts have an age. Fix: Call update_game with account_requirement whole_game in the same call as a minimum age of 16 or 18. https://zaisma.com/developers/errors/accounts_needed_for_minimum_age
- `content_needs_minimum_age` (HTTP 409): A version shows lifelike gore, which plays only in games for 16 and up. Fix: Call update_game with minimum_player_age_years 16 or 18 and account_requirement whole_game, or upload a version without lifelike gore. https://zaisma.com/developers/errors/content_needs_minimum_age
- `gallery_picture_needed` (HTTP 409): A listed game needs at least one gallery picture. Fix: Add a gallery picture with add_image, kind screenshot, then list the game again. https://zaisma.com/developers/errors/gallery_picture_needed
- `bad_link_out_url` (HTTP 400): link_out_url isn't an https address of a site of its own: not a link shortener, an IP address, an address with a user name or a Zaisma address. Fix: Give the https page the game plays on, like "https://kit.itch.io/sky-hopper", or null to remove the listing. https://zaisma.com/developers/errors/bad_link_out_url
- `link_out_not_browser` (HTTP 400): link_out_url is a store, payment or video page, or a download, not a game that plays in a browser. Fix: Give the page players play the game on in the browser (itch.io, your own site), or upload a web build (upload_files) for a Steam or app store game. https://zaisma.com/developers/errors/link_out_not_browser
- `game_hosted_here` (HTTP 409): The game has a live version on Zaisma, so it plays here and can't link out. Fix: Leave link_out_url out, since a listing becomes hosted when a version is published and never the other way. https://zaisma.com/developers/errors/game_hosted_here
- `hosted_only_setting` (HTTP 409): The setting is for games hosted on Zaisma, and this game is a link-out listing (or the listing can't be set while the game has it). Fix: Leave the setting out while the game is a listing, or upload and publish a version to host it here first. https://zaisma.com/developers/errors/hosted_only_setting
- `bad_links` (HTTP 400): links isn't a list of up to 20 { link_name, destination_url, is_on_game_page } with names of their own and https addresses that aren't link shorteners, IP addresses, addresses with a user name, or on Zaisma's own domains. Fix: Give links as a list of up to 20 { link_name, destination_url, is_on_game_page }, each with its own name and an https address on a name of its own. https://zaisma.com/developers/errors/bad_links
- `bad_own_server_urls` (HTTP 400): own_server_urls isn't a list of up to 5 server addresses like wss://play.example.com, or one is an IP address, this computer or on Zaisma's own domains. Fix: Give own_server_urls as up to 5 addresses like wss://play.example.com, on a name of your own. https://zaisma.com/developers/errors/bad_own_server_urls
- `bad_game_server_allowed_hosts` (HTTP 400): game_server_allowed_hosts isn't a list of up to 20 host names (like discord.com or *.example.com), or one is an IP address or on Zaisma's own domains. Fix: Give game_server_allowed_hosts as up to 20 host names like discord.com or *.example.com, with no IP addresses or Zaisma domains. https://zaisma.com/developers/errors/bad_game_server_allowed_hosts
- `built_in_server` (HTTP 403): The game runs a game server built into Zaisma, which only Zaisma changes. Fix: Leave the game's server settings as they are, and ask Zaisma with message_zaisma if one needs to change. https://zaisma.com/developers/errors/built_in_server
- `game_removed` (HTTP 403): Zaisma took the game down, so this can't change. Fix: Read the takedown's review_reason with get_game, and ask Zaisma with message_zaisma if it's unclear. https://zaisma.com/developers/errors/game_removed
- `needs_confirm` (HTTP 409): Hiding a game players can play, or ending a live room, needs the developer's OK. Fix: Ask the developer, then call again with "confirm": true. https://zaisma.com/developers/errors/needs_confirm
- `bad_period_duration_days` (HTTP 400): period_duration_days isn't a whole number from 1 to 90. Fix: Give period_duration_days as a whole number from 1 to 90. https://zaisma.com/developers/errors/bad_period_duration_days
- `bad_cursor` (HTTP 400): cursor isn't a next_cursor from an earlier answer. Fix: Give cursor as the next_cursor of the last answer, or leave it out to start from the top. https://zaisma.com/developers/errors/bad_cursor

## Players

- `no_player` (HTTP 404): No account has that player ID: a guest's, or a deleted account's. Fix: Use a player ID from an account, like one from list_purchases or the game server's player pass, not a guest's. https://zaisma.com/developers/errors/no_player

## Covers, gallery pictures, backgrounds and other images

- `bad_kind` (HTTP 400): kind isn't one of the choices the call takes. Fix: Give kind as one of the choices the call's input schema lists. https://zaisma.com/developers/errors/bad_kind
- `not_an_image` (HTTP 415): The file isn't an image of a type the call takes. Fix: Send a PNG, WebP or JPEG, as base64 or a file. https://zaisma.com/developers/errors/not_an_image
- `image_too_big` (HTTP 413): The image is over 10 MB. Fix: Send the image at up to 10 MB, as WebP or a smaller JPEG. https://zaisma.com/developers/errors/image_too_big
- `bad_image_dimensions` (HTTP 400): The image is smaller than its kind's least size (a cover or gallery picture 1280 by 720, a square cover 512, a share picture 600 by 315), or over 8,192 px on a side. Fix: Send the image at its kind's size: at least 1280 by 720 for a cover or gallery picture, 512 for a square cover, 600 by 315 for a share picture, and at most 8,192 px a side. https://zaisma.com/developers/errors/bad_image_dimensions
- `not_square` (HTTP 400): A square cover isn't as wide as it is tall. Fix: Crop the square cover to as wide as it is tall, at least 512 px a side. https://zaisma.com/developers/errors/not_square
- `too_many_gallery_pictures` (HTTP 400): The game has 8 gallery pictures already. Fix: Remove a gallery picture with remove_image before adding another. https://zaisma.com/developers/errors/too_many_gallery_pictures
- `image_refused` (HTTP 422): The image can't be used. Fix: Read the image's review_reason with get_game and send another image that keeps to the cover guide at zaisma.com/developers/covers. https://zaisma.com/developers/errors/image_refused
- `no_image` (HTTP 404): The game has no image with that ID. Fix: Call get_game for the game's image IDs, then call again with one of them. https://zaisma.com/developers/errors/no_image
- `no_file` (HTTP 400): A form on Zaisma's pages was sent without its image. Fix: Pick an image in the form and send it again. https://zaisma.com/developers/errors/no_file
- `bad_background_shape` (HTTP 400): A wide background is landscape (1.3 to 2.4 times as wide as tall), a phone background portrait (1.6 to 2.4 times as tall as wide), and its long side at least 1600 px. Fix: Send a wide background 1.3 to 2.4 times as wide as tall, or a phone background 1.6 to 2.4 times as tall as wide, with its long side at least 1600 px. https://zaisma.com/developers/errors/bad_background_shape
- `not_a_shader` (HTTP 400): A shader's pass isn't GLSL text with a mainImage function, or has its own main(), a #version or #extension line, texture2D, iMouse or sound. Fix: Write each pass as GLSL with a mainImage function, without main(), #version, #extension, texture2D, iMouse or sound, and test it with check_shader. https://zaisma.com/developers/errors/not_a_shader
- `shader_too_big` (HTTP 413): A shader's pass is over 64 KB. Fix: Keep each pass under 64 KB, moving work into buffers if needed. https://zaisma.com/developers/errors/shader_too_big
- `bad_buffers` (HTTP 400): buffers isn't a list of { buffer_name, source, channels } with buffer_name a, b, c or d, each once. Fix: Give buffers as a list of { buffer_name, source, channels } with buffer_name a, b, c or d, each once. https://zaisma.com/developers/errors/bad_buffers
- `too_many_buffers` (HTTP 400): A shader has more than 4 buffers. Fix: Give a shader at most 4 buffers, a to d. https://zaisma.com/developers/errors/too_many_buffers
- `bad_shader_channel` (HTTP 400): A channel isn't { channel_index 0 to 3, input_kind, buffer_name or image_id, filter, wrap }, names a buffer the shader doesn't have, or a texture that isn't an approved shader_texture of the game. Fix: Give each channel as { channel_index, input_kind, buffer_name or image_id, filter, wrap }, naming a buffer the shader has or an approved shader_texture image. https://zaisma.com/developers/errors/bad_shader_channel
- `shader_texture_too_big` (HTTP 413): A shader texture is over 8 MB, or over 4,096 px on a side. Fix: Send the texture at up to 8 MB and 4,096 px a side. https://zaisma.com/developers/errors/shader_texture_too_big
- `too_many_shader_textures` (HTTP 400): The game has 16 shader textures already, or a shader's channels name more than 4. Fix: Remove a shader texture with remove_image, or give a shader's channels at most 4 textures. https://zaisma.com/developers/errors/too_many_shader_textures
- `shader_texture_in_use` (HTTP 409): A shader the game keeps reads this texture. Fix: Remove the shaders that read the texture with remove_shader first. https://zaisma.com/developers/errors/shader_texture_in_use
- `daily_shader_checks_used` (HTTP 429): The account has run 100 shader checks in the last day. Fix: Wait for the oldest check to pass a day, after retry_after_sec, or check the shader on your own computer with npx @zaisma/cli check. https://zaisma.com/developers/errors/daily_shader_checks_used
- `daily_page_previews_used` (HTTP 429): The account has run every page preview its plan has in the last day (20, or 60 with Pro). Fix: Wait retry_after_sec seconds for the oldest preview to pass a day, or start Zaisma Pro with start_pro for 60 a day. https://zaisma.com/developers/errors/daily_page_previews_used
- `page_preview_unavailable` (HTTP 503): Zaisma can't open pages in Chrome right now, so it can't picture them. Fix: Call preview_game_page again in a few minutes. https://zaisma.com/developers/errors/page_preview_unavailable
- `bad_page_preview_images` (HTTP 400): images isn't a list of up to 8 { kind, image_base64 } or { kind, image_id }, with kind cover, share, screenshot, background or phone_background. Fix: Give images as up to 8 { kind, image_base64 } or { kind, image_id }, with kind cover, share, screenshot, background or phone_background. https://zaisma.com/developers/errors/bad_page_preview_images
- `bad_page_preview_shaders` (HTTP 400): shaders isn't a list of { screen, image, buffers } with each screen at most once. Fix: Give shaders as a list of { screen, image, buffers }, each screen at most once. https://zaisma.com/developers/errors/bad_page_preview_shaders

- `bad_color` (HTTP 400): The color isn't #RRGGBB. Fix: Give the color as #RRGGBB, like #1A2B3C. https://zaisma.com/developers/errors/bad_color

## Clips

- `not_a_clip` (HTTP 415): A clip is one MP4 file, not fragmented, with one H.264 picture track. Fix: Send an MP4 with one H.264 track, like the bench's Record a clip makes, or make one with ffmpeg (libx264, -movflags +faststart). https://zaisma.com/developers/errors/not_a_clip
- `clip_has_sound` (HTTP 400): A clip is silent, and this one has a sound track. Fix: Take the sound track out (ffmpeg's -an) and send it again. https://zaisma.com/developers/errors/clip_has_sound
- `clip_too_long` (HTTP 400): A clip runs at most 6 seconds. Fix: Cut it to at most 6 seconds that loop well (ffmpeg's -t 6) and send it again. https://zaisma.com/developers/errors/clip_too_long
- `clip_too_big` (HTTP 413): A clip is at most 6 MB. Fix: Save it at a lower bitrate (about 4 megabits a second) and send it again. https://zaisma.com/developers/errors/clip_too_big
- `bad_clip_dimensions` (HTTP 400): A clip fits inside 1200 by 630 px, and is at least 600 by 315. Fix: Scale it to fit inside 1200 by 630 px (ffmpeg's scale=1200:630:force_original_aspect_ratio=decrease) and send it again. https://zaisma.com/developers/errors/bad_clip_dimensions
- `bad_clip_still` (HTTP 400): A clip comes with its still: its first frame, a PNG, JPEG or WebP the clip's size, up to 2 MB. Fix: Send the clip's first frame as still_base64, the same size as the clip; the upload command's clip makes it for you. https://zaisma.com/developers/errors/bad_clip_still
- `clip_refused` (HTTP 422): The clip can't be used. Fix: Send a different clip. https://zaisma.com/developers/errors/clip_refused
- `no_clip` (HTTP 404): The game has no clip. Fix: Call get_game to see the game's clip; add_clip sends one. https://zaisma.com/developers/errors/no_clip

## Uploading versions

- `bad_files` (HTTP 400): files isn't a list of files in the shape the call takes. Fix: Give files as a list of { path, content_base64 } or { path, size_bytes, sha256 }, as the call's input schema shows. https://zaisma.com/developers/errors/bad_files
- `bad_path` (HTTP 400): A file's path is absolute, has . or .. in it, has control characters or is over 200 characters. Fix: Give each file a relative path like assets/hero.png, without . or .. parts, control characters or more than 200 characters. https://zaisma.com/developers/errors/bad_path
- `hidden_file` (HTTP 400): A file or folder's name starts with a dot. Fix: Leave out files and folders whose names start with a dot, or rename the ones the game needs. https://zaisma.com/developers/errors/hidden_file
- `precompressed_file` (HTTP 400): A file is pre-compressed (.gz or .br). Fix: Upload with npx @zaisma/cli upload, which unpacks .gz and .br files, or send them unpacked. https://zaisma.com/developers/errors/precompressed_file
- `file_type_not_allowed` (HTTP 400): A file is of a type games can't have. Fix: Leave the file out, or change it to a type games can have, as check_game lists them. https://zaisma.com/developers/errors/file_type_not_allowed
